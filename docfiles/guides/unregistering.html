Guides

Unregistering Events

NodeRemoves
Unregister Event By HandleThe single listener a Register Event handle refers to. The handle is reset.
Unregister All Events For ObjectEvery listener that one object registered, for any event, including its Wait For Event nodes
Unregister EventsEvery listener for every event, and the whole queue

Is Event Handle Registered tells you whether a handle still refers to a registered listener.

Stop listening from one object​

In most cases you want an object to stop listening without affecting anyone else. Use Unregister All Events For Object with self as Object, for example on EndPlay or when a Widget is closed.

To remove only one listener, save the Handle that Register Event returns and pass it to Unregister Event By Handle.

Object must be set on Unregister All Events For Object. If it is empty, nothing is removed and a warning is logged. To remove every listener, use Unregister Events.

Effect on queued events​

Unregistering also cancels calls that are already queued for the removed listeners. A listener that is unregistered in the same frame as an event was invoked will not receive it. Unregister Events clears the whole queue.

It is safe to unregister from inside a callback, including Unregister Events.

Do I have to unregister?​

Not for destroyed objects. They are removed automatically (see Scope and Lifetime). Unregister when an object that is still alive should stop listening, or when you want to clear events on purpose, for example when returning to the main menu.

Deprecated unregister nodes​

Unregister Event, Unregister Event By Object, Unregister Event Name and Unregister Event Name By Object only work with the deprecated Event Identifier and named events. See Migrating to Gameplay Tag Events.

NodeRemoves
Unregister Event By ObjectThe listeners that one object registered for an identifier
Unregister Event Name By ObjectThe listeners that one object registered for a name
Unregister EventAll listeners for an identifier, from every object
Unregister Event NameAll listeners for a name, from every object

With an empty Object, the By Object nodes remove nothing and log a warning.
