Logging and Debugging

Log category​

The plugin logs to the LogEventDispatcher category. Warnings and errors are always shown. To also see every register, invoke and unregister, enable verbose logging with the console command:

Log LogEventDispatcher Verbose

Debug Event Manager​

Call the Debug Event Manager node to print every registered listener (name and type) and every queued event to the Output Log.

Messages​

MessageMeaning
Event (X) was invoked as T but no listener is registered with that typeListeners exist for X, but with a different type. Deprecated events only.
Event (X) is registered as both A and BThe same event is used with two types. Use one type per event. Deprecated events only.
Event (X) was registered without a bound callbackThe Callback pin was not connected. The listener was not added.
No Object was specified, nothing was unregisteredUnregister … By Object was called without an Object.
Event (X) was invoked but has no listeners (verbose)Nobody is listening, or the tag does not match.
Event (X) is already registered for this callback (verbose)A duplicate registration was ignored.
No EventTag was specifiedThe Event Tag pin is empty.
No EventIdentifier was specifiedThe Event Identifier pin of a deprecated node is empty.
No GameInstance foundThe world context has no Game Instance, for example in an editor-only utility.
