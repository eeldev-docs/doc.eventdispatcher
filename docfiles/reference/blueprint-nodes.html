Blueprint Nodes

All nodes are in the Event Dispatcher category and are also available as static C++ functions on UEventManager. The world context pin is filled in automatically in Blueprint.

Gameplay Tag events​

See Gameplay Tag Events.

NodePins
Register EventEvent Tag, Callback (Event Tag, Payload), Include Child Tags (advanced). Returns Handle.
Invoke EventEvent Tag, Payload (Instanced Struct, optional), Optional Target
Wait For EventEvent Tag, Only Trigger Once, Include Child Tags (advanced). Output On Event (Event Tag, Payload).
End TaskStops a Wait For Event
Unregister Event By HandleHandle. Resets the handle.
Is Event Handle RegisteredHandle. Returns whether the listener is still registered.

Register​

Starts listening to a typed event. Callback is the event (usually a Custom Event) that runs when the event is invoked.

NodePins
Register Type EventEvent Identifier (EventIdentifier asset), Callback
Register Type Event NameEvent Identifier (String), Callback

Type is one of Simple, Payload, String, Int, Float, Bool, Vector, String Float or String Int. See Event Types for each callback's signature.

Invoke​

Triggers an event. By default the callbacks run on the next poll, see Dispatching and Timing.

NodePins
Invoke Type EventOptional Target, Event Identifier (EventIdentifier asset), data pin
Invoke Type Event NameOptional Target, Event Identifier (String), data pin

The data pin depends on the type: none for Simple, Payload, String, Value (Int, Float, Bool) or Data (Vector, String Float, String Int). See Targeting a Listener for Optional Target.
