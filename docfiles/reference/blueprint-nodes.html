Blueprint Nodes

All nodes are in the Event Dispatcher category and are also available as static C++ functions on UEventManager. The world context pin is filled in automatically in Blueprint.

Events​

See Gameplay Tag Events.

NodePins
Register EventEvent Tag, Callback (Event Tag, Payload), Include Child Tags (advanced). Returns Handle.
Invoke EventEvent Tag, Payload (Instanced Struct, optional), Optional Target
Wait For EventEvent Tag, Only Trigger Once, Include Child Tags (advanced). Outputs Async Task and On Event (Event Tag, Payload).
End TaskTarget is the Async Task of a Wait For Event. Stops the wait.

By default the callbacks run on the next poll, see Dispatching and Timing. See Targeting a Listener for Optional Target.

Unregister​

NodePinsRemoves
Unregister Event By HandleHandleThe listener the handle refers to. Resets the handle.
Unregister All Events For ObjectObjectEvery listener Object registered, for any event
Unregister EventsAll listeners and all queued events
Is Event Handle RegisteredHandleNothing. Returns whether the listener is still registered.

See Unregistering Events.

Debug​

NodeDescription
Debug Event ManagerPrints every registered listener and every queued event to the Output Log. See Logging and Debugging.

Deprecated nodes​

caution

The Event Identifier and Name nodes below are deprecated since 2.0 and will be removed in a future major version. See Migrating to Gameplay Tag Events.

Register​

Starts listening to a typed event. Callback is the event (usually a Custom Event) that runs when the event is invoked.

NodePins
Register Type EventEvent Identifier (EventIdentifier asset), Callback
Register Type Event NameEvent Identifier (String), Callback

Type is one of Simple, Payload, String, Int, Float, Bool, Vector, String Float or String Int. See Event Types for each callback's signature.

Invoke​

Triggers an event. By default the callbacks run on the next poll, see Dispatching and Timing.

NodePins
Invoke Type EventOptional Target, Event Identifier (EventIdentifier asset), data pin
Invoke Type Event NameOptional Target, Event Identifier (String), data pin

The data pin depends on the type: none for Simple, Payload, String, Value (Int, Float, Bool) or Data (Vector, String Float, String Int). See Targeting a Listener for Optional Target.

Unregister​

NodePinsRemoves
Unregister Event By ObjectEvent Identifier, ObjectThe listeners Object registered for the identifier
Unregister Event Name By ObjectEvent Identifier (String), ObjectThe listeners Object registered for the name
Unregister EventEvent IdentifierAll listeners for the identifier
Unregister Event NameEvent Identifier (String)All listeners for the name
